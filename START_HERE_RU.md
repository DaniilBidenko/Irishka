# Рабочая тетрадь — начните здесь

Обычная инструкция для ежедневной работы на Windows.

## 1. Каждый день

1. Нажмите ярлык **«Рабочая тетрадь»** на рабочем столе (или **«Запустить тетрадь»** / `npm run app:start`).
2. Браузер откроется сам на `http://127.0.0.1:4318`.
3. Интернет не нужен.
4. Перед выключением компьютера дождитесь надписи **«Сохранено»**.

Рабочие данные хранятся в `%LOCALAPPDATA%\WorkNotebook\` — **вне Git**. Команда `npm run dev` — только для разработки (временная папка `.tmp`); для обычной работы её не используйте.

Закладка в браузере работает, пока запущена тетрадь. После перезагрузки компьютера снова используйте ярлык.

## 2. Первый запуск (один раз)

Нужны: Node.js 22+ и Git for Windows (ставит владелец репозитория).

```powershell
cd $HOME
git clone https://github.com/DaniilBidenko/Irishka.git WorkNotebook-source
cd WorkNotebook-source
npm run app:install
```

Одна команда `app:install` без вопросов: поставит зависимости, соберёт программу, создаст базу (валюта RUB) и ярлыки, затем откроет тетрадь.

URL взят из текущего `origin` репозитория. При смене remote обновите строку `git clone`.

## 3. Остановить

Ярлык **«Остановить тетрадь»** или:

```powershell
npm run app:stop
```

Закрытие вкладки браузера сервер не останавливает.

## 4. Резервная копия

Ярлык **«Создать копию»** или `npm run app:backup`.

Копии лежат в `%LOCALAPPDATA%\WorkNotebook\backups`.

## 5. Восстановление

Сначала остановите тетрадь. Затем:

```powershell
npm run app:restore -- --file "C:\путь\к\копии.zip" --confirm
```

Состояние после даты копии в неё не входит.

## 6. Обновление

Ярлык **«Обновить тетрадь»** или `npm run app:update`.

Перед сменой схемы создаётся проверенная копия, затем сборка и **controlled** применение ожидающих миграций. Обычный запуск (`app:start`) миграции сам не применяет.

Без интернета обновление кода недоступно; уже установленная тетрадь продолжает работать офлайн.

`git pull` обновляет только код и **не затирает** базу (она вне репозитория). После появления новых миграций нужен `app:update`. На другом компьютере: clone → `npm ci` → `app:setup`, либо перенесите копию через `app:backup` / `app:restore`.

Раздел **Себестоимость** в шапке — справочник услуг (Полиграфия / Сувенирка / Наружка). В каждой категории: название, себес и редактируемый итог.

## 7. Если что-то не так

| Проблема | Что делать |
|---|---|
| Не открывается страница | Запустите ярлык. Проверьте `npm run app:doctor`. |
| «Порт занят» | Закройте чужую программу на 4318 или смените порт в config явно. Чужой процесс не завершаем. |
| «База не найдена» | Не создавайте новую. Восстановите копию или укажите файл базы. |
| Не сохранилось | Смотрите статус вверху. Повторите «Сохранить сейчас». Не выключайте ПК сразу. |
| Нет места на диске | Освободите место. Не удаляйте единственную копию. |
| Не подходит Node | Установите Node.js 22+ (лучше актуальный LTS). |

**Никогда** не решайте проблему удалением базы «чтобы запустить заново».

Диагностика без изменений данных: `npm run app:doctor`.
