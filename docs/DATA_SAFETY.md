# Сохранность данных

- Рабочие данные: `%LOCALAPPDATA%\WorkNotebook\` (вне Git). Не кладите базу в репозиторий.
- Ежедневный запуск: `npm run app:start` или ярлык «Рабочая тетрадь».
- `npm run dev` пишет в `.tmp/dev-data` — **песочница для разработки**, не для рабочих записей. В шапке будет метка «DEV · временные данные».
- Если пропал файл БД при существующем config — пустая база **не** создаётся автоматически (ни production, ни повторный dev).
- WAL + `synchronous=FULL` + Online Backup API.
- Миграции только через setup/update, не при обычном старте.
- Корзина без автоочистки; физическое удаление в UI v1 нет.

## git pull на другом компьютере

- Pull обновляет **только код**, не затирает SQLite (файлы в `.gitignore`).
- На новом ПК после clone: `npm run app:install` (новая пустая база, без вопросов) **или** перенос копии: на старом `npm run app:backup`, на новом `npm run app:restore -- --file "…" --confirm`.
- Внешнюю папку копий можно позже задать в настройках / через config; при установке по умолчанию не спрашивается.

## Не делать

- Не удалять `.tmp/dev-data` «ради миграции», если там были нужные записи.
- Не решать проблемы удалением `%LOCALAPPDATA%\WorkNotebook\data`.
- Не коммитить `*.sqlite3`, backups, logs.
